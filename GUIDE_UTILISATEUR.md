# Guide utilisateur TrakerDart

## 🎯 Comment ça marche ?

### 1. Démarrer une session
- Cliquez sur **"Démarrer une nouvelle session"**

### 2. Configuration rapide (première fois)
- Choisissez votre main dominante : **Droitier** ou **Gaucher**

### 3. Capture automatique
1. **Activez la caméra**
2. Cliquez sur **"Activer la détection automatique"**
3. Attendez le message "En attente..."
4. **Faites votre premier lancer** naturellement
5. L'appli détecte automatiquement le début et la fin
6. Répétez pour les lancers 2 et 3

### 4. Analyse automatique
Après les 3 lancers, vous voyez :
- **Score de régularité** (0-100%) : Constance entre vos 3 lancers
- **Score technique** (0-100) : Qualité du mouvement
- **Graphiques** : Évolution des angles frame par frame
- **Points à corriger** : Recommandations prioritaires
- **Points forts** : Ce qui fonctionne bien

## 📊 Comprendre les résultats

### Score de régularité
- **90-100%** : Excellent ! Très constant
- **70-89%** : Bon, quelques variations
- **50-69%** : Moyen, manque de constance
- **< 50%** : Travaillez la répétabilité

### Indicateurs analysés
- **Coude** : Amplitude, stabilité latérale/verticale
- **Poignet** : Angle de relâchement, fluidité
- **Épaule** : Rotation parasite, stabilité
- **Tronc** : Inclinaison, balancement
- **Ligne de visée** : Stabilité du regard

## 💡 Conseils pour une bonne détection

### Positionnement
- Distance : **2-3 mètres** de la caméra
- Position : **Profil ou 3/4** (épaule, coude, poignet visibles)
- Éclairage : Uniforme, **pas de contre-jour**
- Arrière-plan : Dégagé, sans mouvement

### Pendant l'enregistrement
- Faites des **gestes complets et naturels**
- Évitez les **faux mouvements** entre les lancers
- Attendez que le message passe à "En attente..." avant le lancer suivant

## ❓ Dépannage

**Le squelette ne s'affiche pas**
→ Améliorez l'éclairage, dégagez l'arrière-plan

**Détection ne se déclenche pas**
→ Faites un geste plus ample

**Lancer détecté trop tôt**
→ Restez immobile avant de lancer

**Score bas sans raison**
→ Vérifiez que tous les points sont bien détectés (verts)

## 🚀 Workflow complet

```
Accueil
  ↓ Démarrer
Calibration (1x)
  ↓ Main dominante
Capture auto
  ↓ 3 lancers détectés
Analyse
  ↓ Résultats
Historique
```

## 📈 Progresser

1. **Regardez vos graphiques** : Identifiez les variations
2. **Lisez les recommandations** : Corrigez 1 point à la fois
3. **Comparez vos sessions** : Historique
4. **Visez la régularité** avant la perfection

---

**Astuce** : Le plus important n'est pas d'avoir un mouvement "parfait", mais d'avoir un mouvement **constant** !
