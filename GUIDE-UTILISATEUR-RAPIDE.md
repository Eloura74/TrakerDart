### 🤖 IA GÉNÉRATIVE (Pro/Elite)

#### Configuration Initiale

**1. Obtenir Clé API OpenAI**
```
1. Allez sur platform.openai.com
2. Créez un compte
3. Section "API Keys" → Nouvelle clé
4. Copiez la clé (sk-...)
```

**2. Configurer TrakerDart**
```
Menu utilisateur → Config IA
→ Coller clé API
→ Choisir modèle (GPT-3.5-turbo recommandé)
→ Ajuster température (0.7 défaut)
→ Sauvegarder
```

#### 💬 Chat Coach IA

**Utilisation**
```
Menu → Chat Coach IA
→ Posez vos questions
→ Obtenez conseils personnalisés
```

**Exemples de questions** :
- "Comment améliorer ma précision ?"
- "Quel exercice pour mon coude ?"
- "Analyse mes 5 dernières sessions"
- "Pourquoi mon score baisse ?"

**Coût** : ~$0.001-0.003 par conversation

#### 📅 Plans d'Entraînement IA

**Générer un Plan**
```
Menu → Plan d'Entraînement
→ Définir objectif (ex: "Améliorer précision 20%")
→ Choisir durée (7-90 jours)
→ Générer
→ Suivre plan semaine par semaine
```

**Le plan inclut** :
- Exercices quotidiens
- Sets/Répétitions
- Notes coach
- Focus hebdomadaire

**Coût** : ~$0.05-0.15 par plan

#### 🎯 Recommandations IA

**Obtenir Recommandations**
```
Session terminée → Analyse
→ Bouton "Générer Recommandations IA"
→ Attendre 5-10 secondes
→ Consulter 3-5 recommandations
```

**Chaque recommandation** :
- Titre + Description
- Priorité (🔥/⚡/💡)
- Actions concrètes
- Raisonnement
- Impact estimé

**Coût** : ~$0.02-0.05 par génération

### 🎯 CALIBRATION ARUCO (Elite)

**Précision Professionnelle +20%**

#### Préparation

**1. Imprimer Cible ArUco**
```
→ Template fourni dans /docs
→ Imprimer A4 qualité maximale
→ Fixer sur cible fléchettes
```

**2. Calibration**
```
Menu → Calibration ArUco
→ Démarrer Détection
→ Positionner cible face caméra
→ Capturer 5-10 frames (angles variés)
→ Cliquer "Calibrer"
→ Vérifier qualité (< 1.0 px = excellent)
→ Sauvegarder profil
```

**3. Activation**
```
→ Profil automatiquement actif
→ Toutes captures utilisent calibration
→ +20% précision garantie
```

## 🐛 PROBLÈMES FRÉQUENTS

### Caméra ne fonctionne pas
```
1. Vérifier permissions navigateur
2. Autoriser caméra pour le site
3. Fermer autres apps utilisant caméra
4. Rafraîchir page
```

### Détection pose imprécise
```
1. Améliorer éclairage
2. Fond uni recommandé
3. Se positionner face caméra
4. Vêtements contrastés
5. → Calibration ArUco (Elite)
```

### IA ne répond pas
```
1. Vérifier clé API OpenAI valide
2. Vérifier crédit OpenAI
3. Config IA → Activer fonctionnalités
4. Rafraîchir page
```

### Vidéo export lent
```
Normal : 720p = 30-60s, 4K = 2-3min
→ FFmpeg.wasm processing côté client
→ Performance dépend appareil
```

### ArUco marqueurs non détectés
```
1. Améliorer lumière
2. Impression haute qualité
3. Marqueurs bien visibles (4/4)
4. Cible face caméra
5. Distance 1-3m optimale
```
